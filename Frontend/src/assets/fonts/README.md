# Inter (Latin subset)

Normal variable WOFF2 supplied by Google Fonts for the existing Inter 400, 500,
600 and 700 weights. The same font file serves all four weights.

- Font source: https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7.woff2
- CSS source: https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap
- Retrieved: 2026-10-24
- SHA-256: `3100e775e8616cd2611beecfa23a4263d7037586789b43f035236a2e6fbd4c62`
- License: SIL Open Font License 1.1; distributed at `public/fonts/Inter-OFL.txt`.
- License source: https://raw.githubusercontent.com/google/fonts/main/ofl/inter/OFL.txt

Vite emits a content-hashed asset shared by the CSS and HTML preload. The font
covers the Latin unicode range from the source stylesheet; other scripts use the
existing system-font fallback stack. No Google Fonts request is made at runtime.
